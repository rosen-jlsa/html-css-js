# HTML, CSS and JavaScript Practice

A collection of front-end exercises and experiments. The working files are under `untitled/`, including `index.html`, `style.css`, and `script.js`, plus numbered and day-based exercise folders.

## View locally

Open `untitled/index.html` in a browser. Edit the adjacent CSS and JavaScript files to explore the exercises. Some subfolders contain separate tasks and should be opened individually.

This is a learning repository rather than a production website.
